# BasaBridge

Students in the Philippines practise reading English for meaning. The plan in docs/PLAN.md is the product authority. The user expanded delivery from a local walkthrough to a public hackathon web app using Groq. Vercel is selected in the user's personal workspace, with separate Neon production and preview databases.

The task is to create an account, read a checked story, answer with the story hidden, and see saved evidence. Parents can see only explicitly shared progress. No invented learner activity is allowed.

The existing design canvas is the visual authority. Preserve its readable type, teal actions, light green background, generous space, and direct language. All interface copy has English and Filipino, simple and standard variants.

Placement, guided lessons, fresh and delayed story rechecks, word practice, optional browser read-aloud and high contrast are implemented. Authored materials begin as drafts; a separate workspace with individual staff accounts and scoped roles records approval of exact content fingerprints. Manual guardian review requires real external identity, relationship and consent verification. A linked guardian's approval and the learner's own consent are both required for an under-13 microphone. Revocation closes access immediately. Review access does not grant general learner progress access. Generation reservations, normalized activity and aggregate service counters support recovery and operation without exposing private content.

Distinguish usable features from release gates: real educator reviews, calibration, speech fairness validation, guardian identity checks and production privacy review cannot be claimed complete by code alone. The user explicitly authorized Groq audio transcription with consent as an exception to the original no-audio-to-model rule. The app never retains raw audio. No real approvals are prefilled.
